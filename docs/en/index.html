Ghost Job Detector

No reply to your application doesn't mean you weren't good enough. Maybe nobody was reading.

A Chrome extension for 104, Taiwan's largest job board. On every listing, it prints the half of the data 104 has but never shows.

01 · The problem

104 only shows you the good half

104 knows how many days ago each listing last processed a résumé and last replied to an applicant, and it already sends those fields to your browser when a listing loads. But the page only shows the good half: "processed résumés within 3 days" appears, while "no reply to any applicant in 30 days" disappears entirely. Applicant counts too: you get a band like "6–10", never the exact number.

This extension fills in the other half, then stays quiet: no scores, no grades, no guessing whether a job is real.

Just three visual cues, none of them a grade:

✓ Green

Résumés processed or replies within 7 days. Good news: HR is actually active.

Red

Posted more than 60 days ago. Worth a second look, not "this job is fake".

Bold on grey

Posted within 60 days. Only meaningful once turned into a day count.

03 · Why no score

Flagging a real job as fake hurts job seekers and companies alike

Early versions had a 0–100 score and four grades, since removed entirely. A sample of 1,039 unique listings on 2026-09-05 showed the premises didn't hold: "the longer it's up, the more abandoned it is" is false. Older listings actually had more active HR.

04 · Install

Manual install, five steps

Not on the Chrome Web Store for now. 104 keeps changing its internal API format, and every store update needs a new review that usually takes weeks. Rather than leave an outdated, possibly broken version in the store, it's manual install only: the code is public and can be updated any time.

  1. Download and unzip

    From the latest release, download ghost-job-detector-x.y.z.zip and unzip it into a folder you won't delete. Chrome reads from that folder every time it starts; move or delete it and the extension stops working.

  2. Open the extensions page

    Type chrome://extensions/ into Chrome's address bar and press Enter.

  3. Turn on "Developer mode" (top right)

    Keep it on after installing. Turn it off and Chrome disables the extension too. This is the most common reason for "installed but nothing happens".

  4. Click "Load unpacked" and pick the folder from step 1

    The button only appears once Developer mode is on. Pick the folder that contains manifest.json, not its parent.

  5. Search any job on 104

    Search on 104 找工作 and every job card gets an extra row of data. Reload any 104 tab that was open before you installed.

When there's a new version: download the new zip and unzip it over the same folder (don't move it), click reload on the extension card in chrome://extensions/, then reload your 104 tabs.

06 · Installed but nothing happens?

Check in this order

Developer mode got turned off

The most common cause. Manually installed extensions only run with it on. Check the switch at the top right of chrome://extensions/.

The 104 tab wasn't reloaded after installing

The extension only loads when a page loads; reload tabs that were already open.

The page isn't supported

It works on 104's search results, AI recommendations, job pages and company pages. Other pages (home, résumé management) get no badge.

The extension is switched off

Click its icon in the toolbar and make sure detection is on.

Chrome asks to "Disable developer mode extensions" on start

Click "Keep", not disable.

The badge says data is unavailable or the format may have changed

104 has probably changed something. The popup shows how many times in a row it failed; please report it on GitHub Issues.
