Privacy policy

Ghost Job Detector (unofficial, for 104) · Last updated 2026-09-03

"Ghost Job Detector (unofficial, for 104)" (the "extension") is a Chrome extension built independently by a third party. It has no affiliation or partnership with 104 Corporation.

We collect no data

The extension does not collect, store or transmit any personal data to the developer or any third-party server. The developer has no servers and no way to see how you use it.

Specifically, it does not collect: personally identifiable information (name, email, address, age, ID numbers and so on), health information, financial and payment information, authentication information (accounts, passwords, cookies, tokens), personal communications, location, browsing history, or user activity (clicks, mouse movement, keystrokes).

How data flows

In your browser, as you, the extension requests 104's internal JSON API (the endpoints 104's own pages call when they load listings, not 104's official key-based API) to get public statistics for a listing (when HR processed résumés, when the company replied, applicant counts) and shows them on 104's page.

These are same-origin requests, sent straight from your browser to www.104.com.tw without any intermediate server. The developer cannot see the requests or the responses.

Local storage

The extension uses chrome.storage.local to keep data on your own computer:

DataPurposeKept for
Search results and job page cacheAvoid requesting the same listing twice, to go easy on 104Expires after 5 minutes
Applicant count cacheSame as aboveExpires after 1 hour
Company listings cacheSame as aboveExpires after 6 hours
Listing observationsHow many times a listing has been repostedUntil you clear it

This data never leaves your device. Clear all of it any time from the extension popup; Chrome also deletes it when you remove the extension.

Permissions

PermissionWhy
storageKeep the cache and observations above on your computer
https://www.104.com.tw/*Show badges on 104's job pages and query the internal API 104's own pages use

It asks for no other permissions and never runs on any site other than 104.

Open source

The full source is public under the MIT license; anyone can read, audit and build it. Released versions match the source: github.com/fansia/104-ghost-job-detector

Changes and contact

If this policy changes, this page is updated along with the "last updated" date above. For any privacy question, please open an issue on GitHub Issues.
