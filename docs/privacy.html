隱私權政策

最後更新:2026-09-03

「幽靈職缺偵測器(104 非官方)」(以下簡稱「本外掛」)是由第三方獨立開發的 Chrome 擴充功能, 與 104 資訊科技股份有限公司無任何隸屬或合作關係。

我們不蒐集任何資料

本外掛不會蒐集、儲存或傳輸任何個人資料到開發者或任何第三方伺服器。 開發者沒有任何伺服器,也沒有任何管道取得你的使用紀錄。

具體而言,本外掛不蒐集:個人身分識別資訊(姓名、電子郵件、地址、年齡、 身分證字號等)、健康資訊、財務與付款資訊、帳號認證資訊(帳號、密碼、Cookie、Token)、 個人通訊內容、地理位置、網頁瀏覽紀錄,以及使用者活動追蹤(點擊、滑鼠移動、按鍵)。

資料如何流動

本外掛在你的瀏覽器中,以你自己的身分向 104 人力銀行的內部 JSON API 發出請求 (即 104 網頁自己載入職缺時就會呼叫的端點,非 104 官方對外開放、需申請金鑰的 API), 取得職缺的公開統計欄位(HR 處理履歷時間、回覆應徵者時間、應徵人數等),並將結果顯示在 104 的頁面上。

這些請求是同源請求,直接由你的瀏覽器送到 www.104.com.tw, 不經過任何中介伺服器。開發者看不到這些請求,也看不到回應內容。

本機儲存

本外掛使用 chrome.storage.local 在你自己的電腦上儲存兩類資料:

資料用途保存期間
搜尋結果與職缺內頁快取避免重複請求同一個職缺,減少對 104 的負擔5 分鐘後失效
應徵人數快取同上1 小時後失效
公司職缺快取同上6 小時後失效
職缺觀察紀錄記錄某個職缺被重新刊登過幾次直到你手動清除

這些資料永遠不會離開你的裝置。你可以隨時從擴充功能的彈出視窗點「清除」一次刪除全部。 移除本外掛時,Chrome 也會一併刪除。

網站上的訂閱表單

本專案的說明網站(GitHub Pages)上有一個「上架時通知我」的連結,會把你帶到 Substack。

  • 這個訂閱與本外掛完全無關。外掛不會蒐集、不會讀取、也不會傳送任何 email。
  • 你的 email 直接交給 Substack 儲存與處理,適用 Substack 的隱私權政策。
  • 說明網站本身沒有嵌入任何第三方追蹤器或 Cookie —— 訂閱是一個外連連結, 你不點就不會有任何資料離開你的瀏覽器。
  • 可以隨時從信件底部退訂。

簡單說:外掛零蒐集這件事沒有變,訂閱是網站上的一個獨立選項,你完全可以不用。
